# Перенаправляем

## 1. Как работают операторы `>` и `>>`?

Оператор `>` перенаправляет стандартный вывод команды в файл. Если файл уже существует, его содержимое перезаписывается. Если файл не существует, он создаётся.

Оператор `>>` дописывает данные в конец файла, сохраняя уже имеющееся содержимое.

Пример использования `>`:

```bash
[student@student-04 ~]$ echo "лИНУКСлИНУКС" > redirect_test.txt
[student@student-04 ~]$ cat redirect_test.txt
лИНУКСлИНУКС
```

Пример использования `>>`:

```bash
[student@student-04 ~]$ echo "Вторая строка" >> redirect_test.txt
[student@student-04 ~]$ cat redirect_test.txt
лИНУКСлИНУКС
Вторая строка
```

Добавление ещё одной строки:

```bash
[student@student-04 ~]$ echo "строка три" >> redirect_test.txt
[student@student-04 ~]$ cat redirect_test.txt
лИНУКСлИНУКС
Вторая строка
строка три
```

## 2. Что такое стандартные потоки `stdin`, `stdout`, `stderr`?

В Linux существуют три стандартных потока:

- `stdin` (standard input) - стандартный ввод, через который программа получает данные.
- `stdout` (standard output) - стандартный вывод, предназначенный для обычных результатов работы программы.
- `stderr` (standard error) - поток для сообщений об ошибках и диагностической информации.

Каждому стандартному потоку соответствует файловый дескриптор:

| Файловый дескриптор | Поток    | Назначение           |
|---------------------|----------|----------------------|
| `0`                 | `stdin`  | Ввод данных          |
| `1`                 | `stdout` | Обычный вывод        |
| `2`                 | `stderr` | Сообщения об ошибках |

Файловый дескриптор - это числовой идентификатор, с помощью которого процесс обращается к открытому файлу или потоку.

## 3. Вывести содержимое файла, не используя текстовые редакторы

Для вывода содержимого файла в терминал используется команда `cat`.

```bash
[student@student-04 ~]$ cat redirect_test.txt
лИНУКСлИНУКС
Вторая строка
строка три
```

Команда `cat` позволяет прочитать файл без использования текстового редактора.

## 4. Создать файл с содержимым, не используя текстовый редактор

Для создания файла с текстом можно использовать команду `echo` совместно с оператором перенаправления `>`.

```bash
[student@student-04 ~]$ echo "Обычный вывод" > stdout.txt
[student@student-04 ~]$ cat stdout.txt
Обычный вывод
```

В результате был создан файл `stdout.txt`, содержащий строку «Обычный вывод».

## 5. На примере подходящих команд выполнить перенаправление потоков

### 5.1. Перенаправить только `stdout` в файл

Для перенаправления стандартного вывода используется оператор `>`.

```bash
[student@student-04 ~]$ echo "Обычный вывод" > stdout.txt
[student@student-04 ~]$ cat stdout.txt
Обычный вывод
```

Обычный вывод команды записывается в файл `stdout.txt`.

### 5.2. Перенаправить только `stderr` в файл

Для перенаправления потока ошибок используется оператор `2>`.

```bash
[student@student-04 ~]$ ls /folder_that_not_exist 2> stderr.txt
[student@student-04 ~]$ cat stderr.txt
ls: cannot access '/folder_that_not_exist': No such file or directory
```

Сообщение об ошибке записывается в файл `stderr.txt`, а не отображается в терминале.

### 5.3. Перенаправить `stdout` и `stderr` в один файл

Для перенаправления обоих потоков в один файл используется конструкция `> all_output.txt 2>&1`.

```bash
[student@student-04 ~]$ ls /tmp /folder_that_not_exist > all_output.txt 2>&1
[student@student-04 ~]$ cat all_output.txt
ls: cannot access '/folder_that_not_exist': No such file or directory
/tmp:
systemd-private-d34d9e52192d41aebf90017f3151e0e6-systemd-logind.service-JF4s26
```

Оператор `>` направляет стандартный вывод в `all_output.txt`, а `2>&1` направляет поток ошибок туда же.

### 5.4. Перенаправить `stdout` и `stderr` в разные файлы

Для раздельного перенаправления используются операторы `>` и `2>`.

```bash
[student@student-04 ~]$ ls /tmp /folder_that_not_exist > only_stdout.txt 2> only_stderr.txt
[student@student-04 ~]$ cat only_stdout.txt
/tmp:
systemd-private-d34d9e52192d41aebf90017f3151e0e6-systemd-logind.service-JF4s26
[student@student-04 ~]$ cat only_stderr.txt
ls: cannot access '/folder_that_not_exist': No such file or directory
```

Обычный вывод сохраняется в `only_stdout.txt`, а сообщение об ошибке - в `only_stderr.txt`.

## 6. Чем отличаются `stdout` и `stderr`?

`stdout` предназначен для вывода обычных результатов работы программы, а `stderr` - для сообщений об ошибках и диагностической информации.

Эти потоки независимы друг от друга. Благодаря этому их можно перенаправлять в один файл или сохранять в разные файлы.

## 7. Что такое `stdin`? Пример передачи данных команде через стандартный ввод

`stdin` - стандартный поток ввода, через который программа получает данные. Источником данных могут быть клавиатура, файл или другая команда.

Пример передачи данных через конвейер:

```bash
[student@student-04 ~]$ echo "линукс линукс" | wc -w
2
```

Команда `echo` передаёт текст, а оператор `|` направляет его в стандартный ввод команды `wc -w`. Команда `wc -w` подсчитывает количество слов и выводит результат `2`.

Пример перенаправления ввода из файла:

```bash
[student@student-04 ~]$ wc -w < redirect_test.txt
3
```

Оператор `<` передаёт содержимое файла `redirect_test.txt` на стандартный ввод команды `wc -w`. Команда подсчитывает три слова.

## 8. Как отправить весь ненужный вывод команды в `/dev/null`?

`/dev/null` - специальное устройство Linux, которое отбрасывает записанные в него данные.

Чтобы скрыть сообщения об ошибках, можно перенаправить `stderr`:

```bash
[student@student-04 ~]$ ls /folder_that_not_exist 2> /dev/null
```

Чтобы скрыть одновременно стандартный вывод и сообщения об ошибках, используется команда:

```bash
[student@student-04 ~]$ ls /tmp  /folder_that_not_exist > /dev/null 2>&1
```

В обоих случаях вывод не отображается в терминале и не сохраняется в обычный файл.

## 9. Чем отличается конвейер `|` от перенаправления `>`?

Оператор `>` перенаправляет стандартный вывод команды в файл. Например:

```bash
echo "Пример" > example.txt
```

Оператор `|` передаёт стандартный вывод одной команды на стандартный ввод другой команды. Например:

```bash
echo "banana apple orange" | sort
```

Таким образом, `>` используется для записи результата в файл, а `|` - для передачи результата другой программе на обработку.

## 10. Собрать команду из двух или трёх программ через `|`

Первый пример - чтение файла, сортировка строк и удаление повторяющихся соседних строк:

```bash
[student@student-04 ~]$ cat redirect_test.txt | sort | uniq
Вторая строка
лИНУКСлИНУКС
строка три
```

Команда состоит из трёх программ:

1. `cat redirect_test.txt` выводит содержимое файла.
2. `sort` сортирует строки.
3. `uniq` удаляет повторяющиеся соседние строки.

Второй пример - разделение строки на слова, сортировка и удаление повторов:

```bash
[student@student-04 ~]$ echo "banana apple orange apple melon berry" | tr ' ' '\n' | sort | uniq
apple
banana
berry
melon
orange
```

В этом примере:

1. `echo` выводит исходную строку.
2. `tr ' ' '\n'` заменяет пробелы переводами строк.
3. `sort` сортирует слова по алфавиту.
4. `uniq` удаляет повторяющиеся соседние строки.

В результате получается список уникальных слов, отсортированных по алфавиту.
