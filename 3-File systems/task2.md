# Структура каталогов

## 1) Какая структура каталогов используется в Linux? Выведите список объектов в корне системы.

В Linux используется иерархическая структура каталогов. Её вершиной является корневой каталог `/`, от которого располагаются все остальные каталоги и файлы.

```bash
ls -la /
```

## 2) Где обычно хранятся домашние каталоги обычных пользователей?

Домашние каталоги обычных пользователей обычно располагаются в `/home`. Для проверки была выполнена команда:

```bash
ls -la /home
```

Результат:

```text
total 20
drwxr-xr-x  5 root    root    4096 Oct 18 09:10 .
drwxr-xr-x 19 root    root    4096 Sep 14 22:34 ..
drwx------  8 student student 4096 Oct 11 11:41 student
drwx------  8 user1   user1   4096 Oct 18 09:34 user1
drwx------  8    1002    1003 4096 Oct 18 09:10 user2
```

В системе обнаружены домашние каталоги `/home/student`, `/home/user1` и `/home/user2`. Для каталога `user2` владельцы отображаются числовыми идентификаторами, а не именами.

## 3) Где находится домашний каталог суперпользователя?

Домашний каталог суперпользователя `root` обычно находится в `/root`.

Для проверки была выполнена команда:

```bash
ls -ld /root
```

Результат:

```text
drwxr-xr-x 5 root root 4096 Oct  7  2025 /root
```

По выводу видно, что `/root` - каталог, владельцем которого является суперпользователь `root`. Он предназначен для хранения личных файлов и настроек суперпользователя.

Основные системные конфигурационные файлы обычно располагаются в каталоге `/etc`.

Каталог `/etc` содержит настройки системы, сетевых служб, пакетов, планировщика заданий и других компонентов.

## 5) Объясните назначение каталогов

- **`/bin`** - традиционное расположение основных пользовательских команд, необходимых для выполнения базовых операций. В данной системе это символическая ссылка на `/usr/bin`.
- **`/sbin`** - традиционное расположение системных команд администрирования. В данной системе это символическая ссылка на `/usr/sbin`.
- **`/usr/bin`** - содержит большинство исполняемых файлов пользовательских программ и команд.
- **`/usr/sbin`** - содержит системные программы администрирования и обслуживания.
- **`/etc`** - содержит системные конфигурационные файлы.
- **`/var`** - содержит изменяемые данные: журналы, очереди, кэши и некоторые данные служб.
- **`/tmp`** - предназначен для временных файлов программ и пользователей.
- **`/home`** - содержит домашние каталоги обычных пользователей.
- **`/root`** - домашний каталог суперпользователя `root`.
- **`/proc`** - виртуальная файловая система `procfs`, предоставляющая информацию о процессах и состоянии ядра Linux.
- **`/sys`** - виртуальная файловая система `sysfs`, предоставляющая информацию об устройствах, драйверах и объектах ядра.

## 6) Проверьте, являются ли `/bin` и `/sbin` реальными каталогами или символическими ссылками в вашей системе.

Для проверки была выполнена команда:

```bash
ls -ld /bin /sbin /usr/bin /usr/sbin
```

Результат:

```text
lrwxrwxrwx 1 root root     7 Apr  6  2024 /bin -> usr/bin
lrwxrwxrwx 1 root root     8 Apr  6  2024 /sbin -> usr/sbin
drwxr-xr-x 2 root root 20480 Sep 27 21:14 /usr/bin
drwxr-xr-x 2 root root 12288 Sep 27 20:23 /usr/sbin
```

Начальная буква `l` в строках `/bin` и `/sbin` означает символическую ссылку. Стрелки показывают, что `/bin` ссылается на `usr/bin`, а `/sbin` - на `usr/sbin`.

Начальная буква `d` в строках `/usr/bin` и `/usr/sbin` означает, что это каталоги.

Следовательно, в исследуемой системе `/bin` и `/sbin` являются символическими ссылками, а `/usr/bin` и `/usr/sbin` - каталогами.

## 7) Найдите, где физически расположен исполняемый файл одной из команд, которой вы пользовались ранее.

Для поиска исполняемого файла команды `findmnt`, использовавшейся в предыдущем задании, была выполнена команда:

```bash
which findmnt
```

Результат:

```text
/usr/bin/findmnt
```

Таким образом, исполняемый файл команды `findmnt` находится по пути `/usr/bin/findmnt`. Команда `which` определяет расположение программы, найденной через каталоги из переменной окружения `PATH`.

### Различия между обычным каталогом, символической ссылкой и виртуальной файловой системой

**Обычный каталог** - объект файловой системы, который содержит записи о файлах и других каталогах. Например, `/etc` и `/usr/bin`.

**Символическая ссылка** - объект, указывающий на другой файл или каталог. Например, `/bin` ссылается на `/usr/bin`, а `/sbin` - на `/usr/sbin`.

**Виртуальная файловая система** предоставляет доступ к информации или интерфейсам ядра, а не просто хранит обычные файлы на диске. Например, `/proc` показывает сведения о процессах и состоянии системы, а `/sys` - об устройствах и объектах ядра. Содержимое таких файловых систем формируется ядром и может меняться во время работы системы.
