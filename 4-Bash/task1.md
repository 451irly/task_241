# Скриптуем по полной

### 1. Что такое shebang?

Shebang - специальная первая строка скрипта, которая указывает операционной системе, какой интерпретатор необходимо использовать для его выполнения.

В созданном скрипте используется:

```bash
#!/usr/bin/env bash
```

Эта строка указывает на использование интерпретатора Bash.

### 2. Обязательно ли расширение `.sh`?

Нет, расширение `.sh` не является обязательным. Операционная система определяет интерпретатор по shebang, а для непосредственного запуска файла необходимо предоставить ему права на выполнение.

### 3. Создание скрипта

Был создан скрипт `file_work.sh`, автоматизирующий основные операции с каталогами, файлами, перенаправлением потоков и конвейерами команд.

Для предотвращения ошибок в начале скрипта используется:

```bash
set -euo pipefail
```

Параметры означают:

- `-e` - завершает выполнение скрипта при возникновении необработанной ошибки команды;
- `-u` - вызывает ошибку при обращении к неустановленной переменной;
- `-o pipefail` - позволяет обнаружить ошибку в любой команде конвейера, а не только в последней.

Рабочий каталог передаётся скрипту первым аргументом командной строки. Если аргумент не указан, скрипт выводит сообщение об ошибке и завершает работу с кодом `2`.

Также реализована проверка существования рабочего каталога `console_work`. Если он уже существует, скрипт не удаляет и не изменяет имеющиеся данные, а завершает выполнение с кодом `3`.

Основные действия записываются в файл `file_work.log`.

**Полный текст скрипта:**

```bash
#!/usr/bin/env bash

set -euo pipefail

if [[ $# -lt 1 || -z "${1:-}" ]]; then
    echo "Ошибка: укажите каталог для работы."
    echo "Пример: ./file_work.sh \"$HOME/script_lab\""
    exit 2
fi

WORK_DIR="$1"

if [[ -e "$WORK_DIR" && ! -d "$WORK_DIR" ]]; then
    echo "Ошибка: указанный путь не является каталогом."
    exit 2
fi

mkdir -p -- "$WORK_DIR"
WORK_DIR="$(cd -- "$WORK_DIR" && pwd -P)"

LOG_FILE="$WORK_DIR/file_work.log"
exec > >(tee -a "$LOG_FILE") 2>&1

log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $*"
}

BASE_DIR="$WORK_DIR/console_work"

if [[ -e "$BASE_DIR" || -L "$BASE_DIR" ]]; then
    log "ОШИБКА: каталог $BASE_DIR уже существует."
    log "Существующие данные не изменены."
    exit 3
fi

log "Начало выполнения скрипта."

TEXT_DIR="$BASE_DIR/documents/texts"
BACKUP_DIR="$BASE_DIR/backup"
REDIR_DIR="$BASE_DIR/redirection"

mkdir -p "$TEXT_DIR" "$BACKUP_DIR" "$REDIR_DIR"
log "Созданы вложенные каталоги."

log "Текущий каталог:"
pwd

cd "$BASE_DIR"
log "Переход в рабочий каталог: $(pwd)"

cd documents/texts
log "Переход в documents/texts: $(pwd)"

cd ../..
log "Возврат в корень рабочей области: $(pwd)"

FILE_A="$TEXT_DIR/file1.txt"
FILE_B="$TEXT_DIR/file2.txt"

printf 'apple\ncherry\nbanana\n' > "$FILE_A"
printf 'apple\npear\nbanana\n' > "$FILE_B"
printf 'Это скрытый файл.\n' > "$TEXT_DIR/.hidden.txt"

log "Созданы текстовые файлы."

log "Список файлов:"
ls "$TEXT_DIR"

log "Список всех файлов, включая скрытые:"
ls -la "$TEXT_DIR"

mv "$FILE_B" "$BACKUP_DIR/file2.txt"
log "Файл перемещён в каталог backup."

mv "$BACKUP_DIR/file2.txt" "$TEXT_DIR/renamed.txt"
log "Файл перемещён обратно в texts и переименован."

cp "$FILE_A" "$BACKUP_DIR/file1_copy.txt"
log "Файл скопирован."

log "Содержимое file1.txt:"
cat "$FILE_A"

log "Сравнение файлов:"
if diff -u "$FILE_A" "$TEXT_DIR/renamed.txt"; then
    log "Файлы совпадают."
else
    STATUS=$?
    if [[ $STATUS -eq 1 ]]; then
        log "Файлы отличаются."
    else
        log "Ошибка сравнения. Код: $STATUS"
        exit "$STATUS"
    fi
fi

sort "$FILE_A" > "$TEXT_DIR/sorted_asc.txt"
sort -r "$FILE_A" > "$TEXT_DIR/sorted_desc.txt"

log "Сортировка по возрастанию:"
cat "$TEXT_DIR/sorted_asc.txt"

log "Сортировка по убыванию:"
cat "$TEXT_DIR/sorted_desc.txt"

log "Поиск файла renamed.txt:"
find "$BASE_DIR" -type f -name "renamed.txt" -print

printf 'Это стандартный вывод stdout.\n' > "$REDIR_DIR/stdout.txt"
log "stdout перенаправлен в stdout.txt."

if ls "$BASE_DIR/nonexistent_file" 2> "$REDIR_DIR/stderr.txt"; then
    log "Команда завершилась без ошибки."
else
    STATUS=$?
    log "Ошибка записана в stderr.txt. Код: $STATUS"
fi

bash -c 'printf "Сообщение stdout.\n"; printf "Сообщение stderr.\n" >&2' \
    > "$REDIR_DIR/combined.txt" 2>&1

log "stdout и stderr записаны в combined.txt."

bash -c 'printf "Отдельный stdout.\n"; printf "Отдельный stderr.\n" >&2' \
    > "$REDIR_DIR/separate_stdout.txt" \
    2> "$REDIR_DIR/separate_stderr.txt"

log "stdout и stderr записаны в разные файлы."

printf 'Первая строка.\n' > "$REDIR_DIR/append.txt"
printf 'Вторая строка добавлена оператором >>.\n' >> "$REDIR_DIR/append.txt"

log "Результат использования > и >>:"
cat "$REDIR_DIR/append.txt"

log "Передача данных через stdin:"
printf 'Первая строка\nВторая строка\nТретья строка\n' \
    | wc -l > "$REDIR_DIR/stdin_result.txt"

cat "$REDIR_DIR/stdin_result.txt"

find "$BASE_DIR" -type f -name "*.txt" > /dev/null 2>&1
log "Вывод команды отправлен в /dev/null."

log "Результат конвейера:"
printf 'pear\napple\npear\nbanana\n' | sort | uniq

log "Итоговая структура:"
find "$BASE_DIR" -print

rm -rf -- "$BASE_DIR"
log "Созданные файлы и каталоги удалены."

if [[ ! -e "$BASE_DIR" ]]; then
    log "Проверка удаления пройдена."
else
    log "Ошибка удаления."
    exit 4
fi

log "Скрипт успешно завершён."
```

Для создания файла использовался heredoc:

```bash
cat > file_work.sh <<'EOF'
```

После вставки текста скрипта вводилась завершающая строка `EOF`.

Для предоставления прав на выполнение использовалась команда:

```bash
chmod +x file_work.sh
```

Запуск скрипта:

```bash
./file_work.sh "$HOME/script_lab"
```

### 4. Проверка работы скрипта

**4.1. Проверка синтаксиса**

Для проверки синтаксиса использовалась команда:

```bash
bash -n file_work.sh
echo "Код проверки: $?"
```

Результат:

```text
Код проверки: 0
```

Код `0` означает, что синтаксических ошибок не обнаружено.

**4.2. Успешный запуск**

Команды:

```bash
./file_work.sh "$HOME/script_lab"
echo "Код возврата: $?"
```

Результат:

```text
[2026-11-08 12:04:12] Начало выполнения скрипта.
...
[2026-11-08 12:04:12] Созданные файлы и каталоги удалены.
[2026-11-08 12:04:12] Проверка удаления пройдена.
[2026-11-08 12:04:12] Скрипт успешно завершён.
Код возврата: 0
```

Скрипт выполнил основные операции и завершился успешно.

**4.3. Запуск без аргумента**

Команды:

```bash
./file_work.sh
echo "Код возврата: $?"
```

Результат:

```text
Ошибка: укажите каталог для работы.
Пример: ./file_work.sh "/home/student/script_lab"
Код возврата: 2
```

При отсутствии аргумента скрипт выводит понятное сообщение и завершает работу с ненулевым кодом возврата.

**4.4. Проверка повторного запуска**

При повторном обычном запуске скрипт успешно выполняет операции заново, поскольку созданный им каталог удаляется в конце выполнения.

Повторный запуск завершился с кодом `0`.

**4.5. Проверка защиты существующих данных**

Для проверки был заранее создан каталог и файл:

```bash
mkdir -p "$HOME/script_lab/console_work"
echo "Важные данные" > "$HOME/script_lab/console_work/important.txt"
```

После этого был запущен скрипт:

```bash
./file_work.sh "$HOME/script_lab"
echo "Код возврата: $?"
```

Результат:

```text
[2026-11-08 12:06:33] ОШИБКА: каталог /home/student/script_lab/console_work уже существует.
[2026-11-08 12:06:33] Существующие данные не изменены.
Код возврата: 3
```

Для проверки сохранности файла была выполнена команда:

```bash
cat "$HOME/script_lab/console_work/important.txt"
```

Результат:

```text
Важные данные
```

Таким образом, при обнаружении существующего рабочего каталога скрипт не перезаписывает данные и завершает работу с кодом `3`.

**4.6. Проверка журнала выполнения**

Для записи действий используется файл `file_work.log`. Вывод команд и сообщения скрипта направляются в журнал с помощью:

```bash
exec > >(tee -a "$LOG_FILE") 2>&1
```

Файл журнала сохраняется в указанном рабочем каталоге и дополняется при каждом запуске.

Пример записей:

```text
[2026-11-08 12:04:12] Начало выполнения скрипта.
[2026-11-08 12:04:12] Созданы вложенные каталоги.
[2026-11-08 12:04:12] Созданы текстовые файлы.
[2026-11-08 12:04:12] Файл перемещён в каталог backup.
[2026-11-08 12:04:12] Файл перемещён обратно в texts и переименован.
[2026-11-08 12:04:12] Файл скопирован.
[2026-11-08 12:04:12] Скрипт успешно завершён.
```

**4.7. Коды возврата**

| Ситуация | Код возврата |
|---|---:|
| Успешное выполнение | `0` |
| Не указан рабочий каталог | `2` |
| Рабочий каталог уже существует | `3` |
| Ошибка проверки удаления | `4` |

В Bash значение `$?` позволяет получить код возврата последней выполненной команды. Нулевое значение означает успешное выполнение, ненулевое - наличие ошибки или особой ситуации.
